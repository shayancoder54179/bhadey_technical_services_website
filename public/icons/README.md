# PWA Icons

Add your app icons here for the web manifest. Required sizes (referenced in `/manifest.json`):

- `icon-72.png`, `icon-96.png`, `icon-128.png`, `icon-144.png`, `icon-152.png`, `icon-192.png`, `icon-384.png`, `icon-512.png`
- `icon-maskable-192.png`, `icon-maskable-512.png` (maskable for splash screens)

Until these files exist, the browser will use its default icon. Generate icons from a single 512×512 source using a tool like [PWA Asset Generator](https://www.pwabuilder.com/imageGenerator) or similar.
